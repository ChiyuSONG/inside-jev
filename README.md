# Jev 模型实测：架构、训练方法与判断边界

**[阅读全文：Jev 模型的架构和训练方法，我们直接问了它自己](https://chiyusong.github.io/inside-jev/)**

Jev 不生成自由文本，而是返回选择、评分和概率。这篇中文文章结合 API 实测与官方资料，讨论它怎样回答关于自身架构和训练方法的问题，以及“零幻觉”、概率和判断能力的边界。

## 文章内容

- **架构与训练方法**：Transformer、预训练模型、知识蒸馏与强化学习。区分模型自述和官方披露。
- **接口与概率**：Choice、Noul 与 Score 的用途，以及选择概率和 confidence 的区别。
- **判断边界**：同义选项、正确答案缺席、选项换序与逻辑悖论。
- **实际用途**：通用判断能力，以及在 Agent 中承担分类、路由和筛选的可能性。

完整问题、结果、配图及来源链接见上方全文。模型对自身的回答不是架构或训练配方的证明，本文也不将少量测试视为全面评测。
